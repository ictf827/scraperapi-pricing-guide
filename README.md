## 关于 API Credits，你需要先搞清楚这件事

在选套餐之前，有一个容易被忽略的关键点：**Credits 不等于请求次数**。

不同类型的请求消耗的 Credits 数量不同：

- 普通 HTTP 请求：1 credit/次
- 启用 JS 渲染（`render=true`）：额外消耗 Credits
- 高级域名（如 Amazon）：更多 Credits/次（Amazon 产品页约 5 credits，加上 JS 渲染后可能到 15 credits/次）

所以如果你主要抓的是受保护的电商页面（比如亚马逊），实际可用请求数会远小于套餐标注的 Credits 数字。一定要在 [官方文档的 Credits 说明页](https://www.scraperapi.com/?fp_ref=coupons) 确认你目标网站的消耗比例，再决定套餐大小。

除了基础代理代理功能，ScraperAPI 还有几个实用的配套工具：

针对亚马逊、谷歌、沃尔玛等热门域名提供预解析的 JSON 数据输出。不需要自己写解析器，直接拿到干净的商品数据、搜索结果、价格信息。

支持批量异步发送请求，适合需要同时处理数百万 URL 的大规模任务，不会阻塞你的主流程。

**DataPipeline**
无代码工具，非开发人员也能配置自动化数据收集任务，不用写一行代码。

**地理定向（Geotargeting）**
全球超过 40M 代理，覆盖 50+ 国家，可以按国家指定出口 IP，适合需要抓取地区限定内容的场景（Business 套餐及以上支持全球国家级定向，Hobby 和 Startup 仅支持美国和欧盟区域）。

**LangChain 集成**
支持直接与 LangChain 连接，用于构建需要实时网页数据的 AI Agent。
